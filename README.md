# Cliploom

A simple video editor for Windows and Android: put clips on a timeline, cut and trim them, add text, stickers, filters and transitions, lay music and voice under it, and export an MP4. Everything runs on your device; nothing is uploaded.

## What it does

- **Timeline**: main video track (videos and photos), text/sticker track, several sound lanes. Drag to move or reorder, drag the white handles to trim, split at the playhead, copy, delete, undo/redo, zoom.
- **Clips**: volume, speed 0.25×–4×, fit/fill, zoom, move, rotate, mirror, 14 filters, brightness/contrast/saturation/warmth, photo slow zoom, 10 transitions (fade, dip to black, flash, slide, push, up, wipe, circle, zoom, blur).
- **Text and stickers**: 13 styles, 7 bundled fonts (OFL), outline, background box, shadow/glow, 6 animations; drag them on the preview.
- **Shapes**: 9:16, 16:9, 1:1, 4:5, 3:4, 21:9 with a blurred or coloured background.
- **Export**: MP4 (H.264, VP9 fallback) at 480p–2K, 24/30/60 fps, rendered frame by frame with WebCodecs; or the soundtrack alone as WAV.

## Sounds

| Source | How |
| --- | --- |
| Your TikTok videos | Save your videos from TikTok (Share › Save video), pick them in *Sounds › My TikTok videos*; the sound is taken out and kept. You can also open TikTok's *Download your data* ZIP (JSON format) to list all your posts with links. |
| Any video | *From a video* takes the soundtrack out of a video file. Media › ⋯ › *Save its sound* and *Detach audio* on the timeline do the same for clips. |
| Audio files | MP3, M4A, WAV, OGG, FLAC… |
| Voice | Record with the microphone, optionally while the video plays. |
| Links | Direct links to audio/video files (not TikTok/YouTube pages). |
| Built-in | 13 effects and 4 music loops generated by code, free to use anywhere. |
| Free music sites | Shortcuts to YouTube Audio Library, Pixabay, Free Music Archive, Freesound, Incompetech. |

Songs from TikTok's sound library are licensed for use inside TikTok only, so Cliploom does not download them; reuse your own sounds or royalty-free music instead.

## Build

```
npm ci && npm start            # Windows/Linux desktop (Electron)
npm test                       # model, TikTok export and WAV tests
cd mobile && npm ci && npm run sync && cd android && ./gradlew assembleDebug   # Android
```

GitHub Actions builds the Windows installer and the Android APK on every push (artifacts *Cliploom-Windows-installer* and *Cliploom-Android-apk*).

Layout: `app/` shared UI (plain JS), `src/` Electron main/preload, `mobile/` Capacitor 8 Android shell, `tools/make-icons.js` icon generator.
